## Installation

Copy the component from `packages/ui/src/components/sections/circuit-bento/` into your project.

```bash
bun add motion clsx tailwind-merge
```

## Usage

```tsx
import { CircuitBento, type CircuitBentoItem } from '@/components/sections/circuit-bento';

const items: CircuitBentoItem[] = [
  {
    title: 'React',
    description: 'The library for web and native user interfaces.',
    href: 'https://react.dev',
  },
  {
    title: 'Motion',
    description: 'Production-grade animation for React.',
    href: 'https://motion.dev',
  },
  {
    title: 'Tailwind CSS',
    description: 'Utility-first styling mapped onto design tokens.',
    href: 'https://tailwindcss.com',
  },
];

export function LandingPage() {
  return (
    <CircuitBento
      hubLabel="Powered By"
      title={
        <>
          Built on a foundation of fast,{' '}
          <span className="text-brand">production-grade</span> tooling
        </>
      }
      items={items}
    />
  );
}
```

## Accessibility

The section is labelled via `aria-labelledby` pointing at a `useId()`-generated heading. The SVG traces are a single labelled image; CPU pins and pulse strokes are decorative. Linked cards expose a concatenated accessible name (`title — description`) and open in a new tab with `rel="noopener noreferrer"`. Traveling pulses are disabled under `prefers-reduced-motion` and pause while the traces are offscreen.

| Key | Action |
| --- | --- |
| `Tab` / `Shift + Tab` | Moves focus through linked tooling cards. |
